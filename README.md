# Behsat Hakan Sağır · Stajyer Avukat

Next.js ile hazırlanmış statik tanıtım sitesi. Renk ve fontlar kartvizitten alındı: lacivert `#11213d`, altın `#c9a572`, başlıklar için **Marcellus**, metin için **Jost**.

## Komutlar

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # statik çıktı: out/
```

`out/` klasörü herhangi bir statik hostinge (Netlify, Vercel, GitHub Pages, cPanel vb.) olduğu gibi yüklenebilir.

## İçerik düzenleme

Tüm metinler `content/profile.ts` dosyasındadır. Özgeçmiş değiştiğinde yalnızca bu dosyayı güncellemek yeterli.
